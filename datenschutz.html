2. Zweck der Datenverarbeitung

Jade Home soll Discord-Server bei der Verwaltung von Support-Tickets, Rollen, Feedback, automatisierten Nachrichten und Sprachkanälen unterstützen.

3. Verarbeitete Daten

Abhängig von den aktivierten Funktionen können folgende Daten verarbeitet werden:

  • Discord-Nutzer- und Server-IDs
  • Benutzernamen und Rolleninformationen
  • Ticketanliegen und Ticketstatus
  • Support-Zuständigkeiten
  • Freiwillig abgegebene Bewertungen
  • Sprachkanal-Beitritts- und Austrittsereignisse
  • Technische Fehler- und Betriebsinformationen

4. Support-Tickets

Bei der Eröffnung eines Tickets werden die zur Bearbeitung notwendigen Angaben verarbeitet. Berechtigte Teammitglieder können das Ticket einsehen.

Nach Abschluss kann der Ticketkanal gelöscht werden. Für eine anschließende Feedback-Anfrage können bestimmte Ticketinformationen vorübergehend gespeichert bleiben.

5. Feedback

Nach einem Ticketabschluss kann Jade Home eine freiwillige Bewertungsanfrage per Discord-Direktnachricht versenden. Abgesendete Bewertungen können in einem konfigurierten Discord-Kanal veröffentlicht werden.

6. Sprachkanäle

Für automatisierte Support-Warteräume können Beitritts- und Austrittsereignisse verarbeitet werden. Eine Aufzeichnung von Sprachgesprächen ist für diese Funktion nicht vorgesehen.

7. Speicherung

Der Bot soll auf einer lokal betriebenen Infrastruktur ausgeführt werden. Die konkreten Speicherfristen werden anhand der tatsächlichen technischen Umsetzung festgelegt.

8. Empfänger und externe Dienste

Jade Home verwendet die Dienste von Discord. Die öffentliche Projektwebseite wird über GitHub Pages bereitgestellt.

Dabei können durch die jeweiligen Anbieter weitere technische Daten verarbeitet werden.
